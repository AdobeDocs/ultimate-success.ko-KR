# 통합 jumpstart: 캠페인 REST API 시작하기

Campaign REST API는 마케팅 또는 서비스 작업과 참여의 순간을 연결하여 중요한 고객 상호 작용을 생성하는 능률적인 방법을 제공합니다. 이 세션은 Ultimate Success 시리즈의 일부이며 이러한 API를 이해하고 효과적으로 활용하는 데 도움이 되도록 설계되었습니다.

## 주요 학습 사항

- 사용 사례를 테스트 가능한 작은 통합 스토리로 변환하는 방법에 대해 알아봅니다.
- API가 가치를 창출하는 위치와 올바른 도구가 아닐 수 있는 위치를 파악합니다.
- 요청 셰이프 만들기, 가드레일 설정 및 제작 경로 설정에 대한 통찰력을 얻으십시오.

## 개요

Adobe Campaign REST API는 단순한 도구가 아닙니다. 즉각적이고 개인화된 고객 상호 작용을 만들 수 있는 게이트웨이입니다. 이러한 API를 사용하면 다음 작업을 수행할 수 있습니다.

- 확인 이메일 보내기 또는 사용자 환경 설정 업데이트와 같은 고객 순간을 기반으로 특정 작업을 트리거합니다.
- Adobe 및 외부 시스템을 포함한 다른 애플리케이션과 원활하게 통합할 수 있습니다.
- 포기한 장바구니 알림, 환영 이메일 및 트랜잭션 확인과 같이, 지연 시간이 짧은 이벤트 중심의 사용 사례를 지원합니다.

## 주제

1. **비즈니스 개요:**
   - REST API의 전략적 개념.
   - API 활용에 대한 고객 순간 식별.
2. **기술 인사이트:**
   - API 끝점 구성 및 인증.
   - IMS 인증 및 개발자 콘솔 프로젝트 설정.
   - 끝점 선택 및 페이로드 사용자 지정 이해.
3. **데모:**
   - Adobe Campaign에서 이벤트 유형 및 템플릿 구성.
   - SOAP 및 REST API 호출에 Postman 활용.
   - API 호출 및 해당 결과의 실제 예.

이 세션은 다음 경우에 이상적입니다.
