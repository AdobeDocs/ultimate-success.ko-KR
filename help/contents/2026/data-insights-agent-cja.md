# CJA에서 Adobe Data Insights Agent 작업

Adobe Data Insights Agent을 Customer Journey Analytics 내에서 실용적인 일상적인 워크플로우로 만드는 방법을 알아봅니다. 이 세션은 팀이 자연어를 사용하여 분석을 가속화하고, 셀프서비스 통찰력을 활성화하고, 수동 보고에 대한 의존도를 줄이는 방법을 보여 줍니다. 조직에서 insight에 대한 시간을 향상시키고 데이터 중심의 의사 결정을 확장하려는 경우 이는 반드시 지켜봐야 할 사항입니다.
