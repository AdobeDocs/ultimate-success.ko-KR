# AEP에서 Federated Audience 구성 잠금 해제: 데이터 사일로에서 Unified Audiences로

Adobe Experience Platform에서 선도적인 조직이 데이터 사일로를 분류하고 FAC(Federated Audience Composition)를 통해 실시간 고객 참여를 해제하는 방법을 알아봅니다. 이 세션에서는 데이터를 복제하지 않고 데이터 웨어하우스와 Real-Time CDP을 원활하게 연결하여 고부가가치 대상자를 구축하고 활성화하는 방법에 대해 알아봅니다. 라이브 데모를 통해 마케터에게 친숙한 인터페이스를 사용하여 데이터를 모델링하고, 대상을 만들고, 보다 개인화된 즉각적인 경험을 추진하는 방법을 살펴볼 수 있습니다. 데이터 거버넌스 및 효율성을 유지하면서 개인화를 확장하려는 경우 이 세션은 이를 구현하는 방법에 대해 실용적이고 종합적인 보기를 제공합니다.
