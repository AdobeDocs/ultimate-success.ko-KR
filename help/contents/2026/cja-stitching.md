# Adobe Customer Journey Analytics 스티칭으로 크로스 채널 인사이트 향상

이 웨비나는 Adobe Customer Journey Analytics(CJA)의 ID 결합을 더 신비화하고 실제 사람 수준의 크로스 채널 분석을 잠금 해제하는 방법을 보여 줍니다. 스티칭이 인증된 이벤트와 인증되지 않은 이벤트를 일반 개인 ID에 연결하여 웹, 앱, 콜 센터 및 오프라인 데이터 소스 전반에 걸쳐 적용 범위를 개선하는 방법을 안내합니다. 참석자는 필드 기반 및 그래프 기반 결합 간의 차이점, 각 결합 사용 시기 및 데이터 및 ID 전략에서 필요한 사항에 대해 알아봅니다. 결국 참가자는 CJA에서 결합된 데이터 세트의 유효성을 검사하고 이를 보다 정확한 보고, 속성 및 대상자 빌드로 변환하는 방법을 이해하게 됩니다.

>[!VIDEO](https://video.tv.adobe.com/v/3497282/?learn=on&enablevpops)

이 웨비나에서는 다음 내용을 다룹니다.

* 결합을 통해 개인 수준, 크로스 채널 분석을 활성화하는 방법 - 참석자는 CJA 결합이 일반적인 개인 ID에 대한 이벤트를 통합하여 팀이 쿠키, 장치 또는 채널 수준 보기로 제한되지 않고 장치 및 채널에서 여정을 분석할 수 있도록 하는 방법을 알아봅니다.
* 필드 기반 결합과 그래프 기반 결합의 차이점 - 세션은 필드 기반 결합이 적합한 경우와 그래프 기반 결합이 적합한 경우를 명확히 하며, 특히 데이터 세트에서 여러 식별자를 사용하고 더 복잡한 ID 환경을 가진 조직의 경우 더욱 그러합니다.
* 보고, 속성 및 활성화를 위한 결합의 비즈니스 가치 - 참석자는 더 강력한 ID 해결로 접점 간의 속성이 향상되고, 보다 완벽한 여정 분석을 지원하고, 다운스트림 작업에 대한 대상을 찾는 데 어떻게 도움이 되는지 확인할 수 있습니다.
